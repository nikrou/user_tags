Forma d'ús

Si l'usuari té el permís "Afegir" i es mostren les etiquetes sobre una imatge, es poden editar etiquetes relacionades clicant a la icona "edita".

Permisos

Els permisos estan units a l'estatus dels usuaris (visitant, genèric, usuari normal, administrador, webmaster). Els usuaris poden fer una acció (afegir, eliminar) només si tenen l'estatus més gran que el seu propi configurat

Els usuaris poden eliminar etiquetes que hagin afegit abans, inclús si no es vol que es puguin eliminar etiquetes relacionades.

Podeu permetre que un usuari pugui afegir només etiquetes existents si el quadre de verificació "només etiquetes existents" està actiu..
